# 本地德州扑克生涯 V2.0

纯本地、完全离线、单人游玩的中文德州扑克生涯小游戏。真人玩家始终只有一个，其余座位由只读取公开信息和自己底牌的 AI 控制。筹码是游戏内数值，不涉及真钱、账号、服务器、联网匹配、广告或充值。V2 在保留原有现金牌桌的基础上加入了可恢复的现金买入和六人 Mini 锦标赛。

## 开始使用

### 朋友直接游玩

公开网页地址：

<https://ywang717.github.io/local-poker-game-v1/>

朋友打开链接即可在电脑或手机上创建自己的本地生涯。首次打开需要联网下载页面；页面缓存完成后，游戏逻辑和存档都可以离线运行。

仓库维护者第一次发布时，需要在 GitHub 仓库的 **Settings → Pages** 中将发布来源设为 **GitHub Actions**；之后推送到 `main` 会自动构建并发布。

- 电脑：使用 Chrome、Edge 或 Safari 打开链接，也可以通过浏览器地址栏的安装按钮添加到桌面。
- iPhone Safari：打开链接，点击“分享”→“添加到主屏幕”。
- Android Chrome：打开链接，选择“安装应用”或“添加到主屏幕”。
- 手机和电脑各设备独立保存生涯，不会自动同步；清理浏览器网站数据会删除该设备的本地存档。
- 当前版本是单人 AI 游戏，不支持朋友之间联机同桌。

在仓库根目录执行：

```bash
npm install
npm run dev
```

浏览器打开 Vite 输出的本地地址即可开始。生产构建和测试命令：

```bash
npm run build
npm test
npm run typecheck
npm run test:simulation
```

发布门禁依次运行 `npm ci`、类型检查、默认单元与集成测试、AI、现金买入、锦标赛、小规模 Smoke 和生产构建；任一门禁失败都不会上传 GitHub Pages 构建产物。默认测试排除大型连续模拟和发布 Smoke，Smoke 在发布流程中只运行一次。

`npm run test:simulation` 会运行标准德州与短牌在 2、3、4、5、6、8、9 人桌上的连续牌局压力测试，共 14,000 手，并检查弃牌、下注、All-in、边池、退款和筹码守恒。

当前版本支持 Windows、macOS、iPhone 和 Android 的现代浏览器；Tauri/Electron 外壳不属于本版本发布门槛。

## 功能范围

- 标准德州与短牌德州（36 张牌、同花大于葫芦、A6789 顺子）。
- 2、3、4、5、6、8、9 人桌，Heads-Up 盲注和行动顺序单独处理。
- 5 档盲注、买入、永久解锁和破产保护。
- 五档信息边界安全的启发式 AI，难度来自策略参数，不改变洗牌或发牌。
- All-in、多层主池/边池、Split Pot 和固定奇数筹码规则。
- 生涯资金、模式/人数/级别统计、最近 500 手牌及行动时间线。
- 暂停、结算后继续下一手或离开牌桌、可取消 AI 思考节奏、真人无行动倒计时和短牌规则提示。
- 结算画面默认显示上一手回顾；进入下一手后可展开查看玩家底牌、公共牌、底池派奖和行动时间线。

## V2 使用说明

### 恢复牌局和存档

生涯、当前手牌、最近 500 手牌和设置保存在浏览器 IndexedDB 中。V2 使用 `saveVersion: 2`；旧版 V1 生涯和手牌记录会在读取时补齐 V2 字段。保存当前手牌时会保留上一份有效备份，当前记录损坏会自动尝试备份；两份都无法读取时，界面会显示“存档无法恢复”，不会静默创建一份新生涯。清理浏览器网站数据会删除该设备上的本地记录。

### 现金牌桌买入

在现金牌桌工具栏点击“买入”即可提交下一手生效的买入申请，目标筹码最多为当前等级的 100BB。申请中的资金会单独记录，确认、取消、离开牌桌和页面重新打开都保持幂等；多余金额会退回生涯资金。结算后筹码为零时，可以选择重新买入后继续，或离开牌桌取回剩余资金。Mini 锦标赛不显示现金买入按钮。

### 生涯数据与起手牌胜率

生涯主页点击“查看锦标赛生涯”，或在“生涯数据”中切换“现金桌 / 锦标赛”。锦标赛展示已结算参赛次数、冠军次数与冠军率、前三次数、最佳名次、报名费、奖金及净收益，并保留最近 500 场结果（含主动退出）。未确定冠军的比赛不显示冠军名字。

两种生涯分别按标准德州 / 短牌统计 AA、AKs、AKo 等起手牌的实战结果。胜率 = 单独获胜手数 / 发到该组合的手数；平分单独列出，弃牌计入未获胜。真人淘汰后的观战手牌不计入；锦标赛筹码不计入现金桌盈利。累计统计不会因手牌或比赛历史截断而减少。

旧存档保留原累计数据，一次性从明确标记为锦标赛的本地手牌历史补算起手牌结果。无法恢复的旧比赛不生成记录；前三次数及逐场记录从页面注明的统计起点开始。新增字段用兼容迁移标记初始化，沿用 saveVersion 2 与现有牌局快照。

### Mini 锦标赛

从生涯进入“Mini 锦标赛”，选择标准德州或短牌及已解锁等级，支付一次报名费后进入固定六人桌。盲注按锦标赛级别增长，淘汰后保留排名；最后一名玩家获得冠军，冠军奖金和锦标赛统计与现金牌桌资金分开记录。中途离开会记录弃赛结果；关闭页面后重新打开会恢复当前锦标赛手牌、盲注和淘汰信息。锦标赛没有现金买入或 Rebuy。

### 手机使用

手机浏览器使用与电脑相同的本地存档和离线缓存。iPhone Safari 选择“分享”→“添加到主屏幕”，Android Chrome 选择“安装应用”或“添加到主屏幕”；横向或竖向屏幕都可操作，买入弹窗和主要按钮保留触控所需的最小尺寸。每台设备的生涯互相独立，不会自动同步。

## 本地存档

存档使用 IndexedDB，数据库名为 `local-poker-game-v1`，包含 `career`、`currentHand`、`handHistory` 和 `settings` 对象存储。每次关键保存会保留上一份有效记录作为备份；当前记录损坏时自动回退到备份，两个记录都损坏时返回可处理的“存档无法恢复”状态。

存档带有 `saveVersion`。`src/storage/migrations.ts` 负责把旧版本数据迁移到当前结构。当前牌局快照保存完整有序牌堆、`deckIndex`、底牌、公共牌、筹码、行动玩家、投入、边池和行动历史，恢复时不会重新洗牌；结算状态会等待玩家选择继续或离开。手牌历史在保存和加载时都限制为最近 500 手，并保存每个底池的获胜者与派奖。真人牌局使用唯一 Hand ID，避免离桌重进后历史去重冲突。

## 技术架构

```text
src/game       牌、牌型、庄位、下注状态机、边池和结算
src/ai         公开信息上下文、范围参数、启发式决策、玩家模型
src/career     生涯资金、解锁、统计和手牌历史
src/storage    IndexedDB、备份轮换、迁移、当前手牌快照
src/store      Zustand 生涯、牌局、设置状态
src/components React 牌桌、牌、底池和操作区
src/pages      主页、生涯、选桌、牌局、统计、历史、设置
```

扑克规则、合法下注、边池、AI、资金、存档都位于 React 页面之外。AI 上下文类型不包含真人底牌、其他未公开底牌、未来公共牌、牌堆顺序或最终胜负。

## 离线保证

运行时不请求远程 API，不建立 WebSocket，不需要登录或网络服务。随机洗牌使用注入的 Fisher-Yates 随机源；生产桌面壳可以在后续接入 Tauri，但不应改变本地引擎和 IndexedDB 存档契约。
