日期：2026-10-02

版本范围：AI 体验修复、现金桌补码一致性、Mini 锦标赛观战快速模拟

## 修复项

- 锦标赛 AI 使用实际存活参赛者数量；当前手弃牌不会改变 `playersRemaining`。
- AI 位置统一由固定座位映射提供，六人桌保持 `BTN / SB / BB / UTG / HJ / CO`，弃牌不会重排位置。
- 每个 AI 在牌桌创建时获得稳定 Personality，并随下一手和存档恢复保留。
- 现金桌下一手切换使用统一的 Career + Hand Snapshot 原子写入；买入 Apply、Cancel、Refund 按交易 ID 幂等。
- Pending 买入可以真实取消；达到 100BB、余额不足或已申请离桌时给出禁用原因。
- LV4/LV5 多人底池 Equity 为所有对手发放不重复的未知牌，并按平分底池计算 Equity。
- Showdown 只统计至少两名未弃牌玩家进行牌型比较的牌局，另计 `Won Without Showdown`。
- 真人淘汰后可继续观战、快速使用真实引擎模拟至唯一冠军，或退出比赛。
