# V2.3 Acceptance

## Scope

V2.3 fixes short all-in raise rights, all-in call versus jam classification, relevant effective-stack inputs, post-flop value/semi-bluff raises, board features, opponent-model sampling, and the cash next-hand durable boundary.

## Verification

- Typecheck: PASS (`npm run typecheck`)

- AI tests: PASS (20 files, 119 tests)

- Tournament tests: PASS (6 files, 21 tests)
- Release smoke: PASS (800 AI hands, 600 rules hands, 20 tournament smoke cases)
- Build: PASS (`vite 8.3.2`)
- Full simulation: NOT RUN (manual command remains `npm run test:simulation:full`)

## Dependency audit

Vite was upgraded from 8.0.13 to 8.3.2 and Vitest from 3.2.4 to 3.2.7. The remaining audit report contains two moderate `@vitest/mocker`/Vitest findings; the available fix requires Vitest 5, a major upgrade outside this release scope. No force upgrade was used.

## Persistence boundary

The cash next-hand path flushes queued writes, atomically persists Career plus the next-hand snapshot, and only then publishes the next hand to Zustand. A regression test covers delayed persistence with instant AI timing.
