# Local Poker Game V2.2 验收记录

## 修改范围

- 统一固定座位位置与 Heads-Up BTN/SB、BB、IP/OOP 角色。
- Facing Open 改为 Fold / Call / 3-Bet 三路响应，移除固定底池比例 Call 门槛；加入开池尺度、位置、Caller Count、Squeeze、性格边缘调整。
- Facing 3-Bet / 4-Bet 与 All-in 使用独立分支；深筹码 All-in 响应收紧，短筹码保留 Push/Fold 方向。
- 相关 Effective Stack 使用 Opener / Last Aggressor，不再被无关短筹码覆盖。
- Postflop 接入 Personality，但不修改 Equity、Pot Odds、SPR 或对手数量。
- 标准手牌记法使用 `T`。
- 现金桌下一手过渡增加 Game/Career persistence queue flush、无副作用内存更新和失败回滚；Transaction ID 仍保持 Apply/Cancel 幂等。
- 默认测试排除完整 14K 模拟和 release smoke；完整模拟保留为 `npm run test:simulation:full`，release smoke 只通过 `npm run test:simulation:smoke` 执行。
